## 🚀 Features

| Feature | Description |
|---------|-------------|
| Conflict Scanner | Detects known conflicting mod combinations before they crash your game |
| Outdated Mod Alerts | Warns when installed mods are outdated for the current game patch |
| Script Error Log | Detailed logging of mod script errors for troubleshooting |
